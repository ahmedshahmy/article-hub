# Article Hub

A mobile-friendly web app for hosting articles with one image each.

## Features
- Create articles with title, content, and one image
- View articles organized by month
- Mobile-responsive design
- Local storage persistence

## Files

- `upload.html` - Create new articles
- `view.html` - View articles organized by month
- `assets/style.css` - Shared styling
- `assets/script.js` - Shared JavaScript functionality

## How to Use

1. Open `upload.html` to create new articles
2. Open `view.html` to view articles organized by month
3. All data is stored locally in your browser

## Deployment to GitHub Pages

1. Create a new repository on GitHub
2. Add these files to your repository
3. Enable GitHub Pages in repository settings
4. Your site will be available at `https://username.github.io/repository-name`
